# Java Social Network Model

![Java](https://img.shields.io/badge/Java-basics-ED8B00?logo=openjdk&logoColor=white)

A small Java domain-model exercise for representing a social network and managing a collection of users. The sample centers on user lookup and basic add/remove operations.

## Project status

This is an early learning example. It references a `User` model that is not included, so additional classes are needed before the project can be compiled as a complete application.
